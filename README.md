# Portal do GECEP

Código completo do portal do Grêmio Estudantil do Colégio Estadual do Paraná.

O projeto possui páginas públicas, calendário, notícias, projetos, equipe, documentos, transparência, formulários, painel administrativo, banco de dados e envio de arquivos.

## Funcionalidades documentadas

- [Mapa do Colégio](docs/mapa-do-colegio.md): busca pública de salas e turmas, gestão de ensalamentos, banco, carga inicial e testes.
- [Pendências do Mapa do Colégio](docs/pendencias-mapa-do-colegio.md): informações que não puderam ser confirmadas no PDF de referência.
- [Eventos internos](docs/eventos.md): central pública, cadastro, estados, arquivos, migrações e publicação.
- [Interclasses](docs/interclasses.md): campeonatos, participantes, chave, jogos, resultados e correções.
- [Reuniões e atas](docs/reunioes-e-atas.md): resumos, presenças históricas, documentos e votações.
- [Representantes](docs/representantes.md): busca pública, mandatos, troca de representante e privacidade.
