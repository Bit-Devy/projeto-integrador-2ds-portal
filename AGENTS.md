# orientações do projeto

- este é o portal do gecep, o grêmio estudantil do colégio estadual do paraná
- preserve o estilo de código já usado no projeto e prefira nomes claros em português
- coloque um comentário acima dos blocos de código mais importantes explicando o que fazem
- escreva os comentários com letras minúsculas, sem ponto final e em linguagem extremamente simples
- não é necessário comentar cada linha ou cada bloco pequeno
- use o site oficial do colégio como principal referência visual para novos recursos: https://www.cep.pr.gov.br/
- mantenha as informações, os conteúdos e o banco de dados próprios do grêmio
- a referência do colégio orienta a aparência e não substitui a identidade nem os dados do gecep
